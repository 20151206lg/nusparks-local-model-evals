# Eval 5: Inkling 2 Mini on Strata, one model on two tasks (RTB at two thinking levels, rocket game at medium)

> **Read the safety section first.** These scripts run an autonomous coding agent with a shell and run code it wrote; use a disposable environment. The rocket harness (eval 3, patched here) can **enable, disable and restart your macOS LaunchAgents** (`swap.sh`; it refuses to run unless you set `EVAL_ALLOW_SERVICE_CHANGES=1`). The Inkling cells do not call `swap.sh`: Strata runs as its own daemon (see [`server/`](server/)). See [Safety](#safety).

**Question:** how does Thinking Machines Lab's Inkling 2 Mini (a 26.4B-parameter mixture-of-experts model that uses 3.4B parameters per token), packed by the Strata project as `SQ-20` and served by Strata on a Mac, do on the tasks from evals 1 and 3 — the ad-exchange task round by round, with thinking **off** and at **medium** effort, and the rocket game in Godot and in Python with Panda3D at medium, plus a second Python run through OpenCode instead of Pi, and the Python game again on a different engine (pygfx)? One run per arm or cell, one Mac, so these are anecdotes, not a ranking.

## Setup

- Model: [`strata-engine/Inkling-2-Mini-Strata`](https://huggingface.co/strata-engine/Inkling-2-Mini-Strata), pack `Inkling-2-Mini-SQ-20.strata` (19.35 GB; the page says it matched the original model's next-word choice in 100% of its tests). Base model [`thinkingmachines/Inkling-2-Mini`](https://huggingface.co/thinkingmachines/Inkling-2-Mini): Apache 2.0 with a Model Acceptable Use Policy, per the Strata page as read on 2026-11-26; the exact revision was not recorded. A looped transformer: the middle layers run three times per token.
- Server: Strata 0.2.22 (engine `strata-inkling` 0.1.67, Metal), command in [`server/strata-launch.sh.example`](server/strata-launch.sh.example): 128K context (131,072 tokens), one request at a time, vision off, localhost only, no API key. Strata measured its own draft decoding at 1.07x on one launch and 1.09x on another, under its 1.10x bar, and left it off. Strata itself is MIT-licensed.
- Agent: Pi 1.5.2, `-nc` (no context files), model entry in [`server/pi-models.json.example`](server/pi-models.json.example) (`contextWindow` 131072, `maxTokens` 16384, temperature 1.0). The RTB task was run at Pi thinking level `off` (`enable_thinking` false) and at `medium` (`reasoning_effort` medium); the rocket cells only at `medium`. [`server/opencode.jsonc.example`](server/opencode.jsonc.example) is the config used for a short OpenCode 2.x smoke test (not part of the results).
- Hardware: Apple M3 Max, 30-core GPU, 36 GB. Measured with thinking off: decode about **33 tok/s** (Strata's own probe 34), prefill 526-623 tok/s (429 tok/s at 88K tokens), needle retrieval correct at 11.6K, 23.4K, 45.8K and 88.6K tokens, 30 of 30 tool calls parsed (1.0 s per round), GPU in use 23.2 of 28.1 GiB at a 64K context and 24.8 GiB with an 88K-token prompt at 128K (3.3 GiB of headroom, so nothing else may use the GPU). Strata's page lists faster figures for other machines (for example 108.9 tok/s on an M5 Max with SQ-20); we did not reproduce those.
- Thinking: on by default. `enable_thinking: false` and `reasoning_effort: none` both gave 0 reasoning characters on a trivial prompt; medium effort gave about 5,600 characters and 10 times the tokens on a harder one. The model card says reasoning "cannot be switched off fully": in the agent runs with thinking "off" a minority of turns still carried reasoning (75,026 characters over 688 calls).
- Hosted assistant (Claude Code): wrote the fix lists, probes and mutation checks, audited every round, and decided what counted as correct. The local model made every repair.

## Procedure

1. **Eval 1 (ad exchange), two arms.** [`bin/init_run.sh`](bin/init_run.sh) makes a worktree from a branch holding only [eval 1's `TASK.md`](../1-rtb-single-agent/TASK.md). Round 1: [`prompts/C1.txt`](prompts/C1.txt), tools `read,edit,write` only (no shell, as the task says). After each round the assistant ran the suite repeatedly, a direct probe of the rules ([`accept/probe_rtb.py`](accept/probe_rtb.py) for the off arm's code, [`accept/probe_rtb_medium.py`](accept/probe_rtb_medium.py) for the medium arm's) and a mutation check ([`accept/mutate_rtb.py`](accept/mutate_rtb.py), [`accept/mutate_rtb_medium.py`](accept/mutate_rtb_medium.py): put each bug back in a copy; a suite that stays green cannot guard that rule), read the code and Pi's report, then sent a fix list naming only demonstrated defects ([`prompts/R2.txt`](prompts/R2.txt) and `R3.txt` for the off arm, whose round 4 repeated `R3.txt` because round 3 had made no change; `R2m.txt` and `R3m.txt` for the medium arm) with `bash` enabled. [`bin/round.sh`](bin/round.sh) runs a round with wall, tool-call and idle caps enforced from outside; use `FRESH=1` to start a new Pi session for a later round (continuing a session carries the whole earlier context). The two arms used one model, one server and one task; only Pi's thinking level differed.
2. **Eval 3 (rocket game), Godot and Python, medium effort.** Same harness as eval 3 with an `inkling` target: [`rocket-inkling.patch`](rocket-inkling.patch) is the change to `run_cell.sh` (a health check on :8001 instead of `swap.sh`), `accept_watch.sh` (`CELLS` variable) and `capwatch.py` (SIGKILL escalation), plus a new `bin/run_inkling.sh` (apply from the repository root with `git apply evals/5-inkling/rocket-inkling.patch`). Set Pi's `defaultThinkingLevel` to `medium`, start Strata, then `run_cell.sh G inkling 90 400` and `run_cell.sh P inkling 90 400` (for the OpenCode run: set `OPENCODE_RUN_CONFIG_HOME` to the folder holding [`server/opencode-rocket/opencode/opencode.jsonc`](server/opencode-rocket/opencode/opencode.jsonc) and run `run_cell.sh P inkling-oc 90 400`, or `bin/run_inkling_oc.sh`) (wall cap 90 min, tool-call cap 400, idle cap 1200 s), and `run_accept.sh <cell>` for each. Same prompts and acceptance probes as eval 3.

The RTB probes and mutation checks are tied to the exchange each arm wrote (class names, module layout, the source lines the mutations patch), so they need adapting for another model's code. The rocket probes are eval 3's and are model-independent; the reference passes them 11 of 11 (Godot) and 14 of 14 (Python controller).

## Result in one screen

| Task | Result | Time, calls |
|---|---|---|
| Ad exchange, thinking off | Exchange correct after round 2; tests able to fail after round 4, after a round 1 that never finished (195 reads of one file, stopped by hand) and a failed round 3; the 10 ms headroom guard was weak | about 105 min, 688 calls |
| Ad exchange, medium | Round 1 finished; exchange correct after round 2; 17 of 17 mutation checks in the standard batch caught after round 3, plus the separate 10 ms headroom check | about 49 min, 74 calls |
| Rocket game, Godot, medium | **Playable game: our probe 11 of 11** (the probe has 10 checks and an 11th, "the round stops after a win", that runs only if some policy wins; the untouched project scores 3 of 10, the reference 11 of 11) | 41 min, 63 calls, finished |
| Rocket game, Python/Panda3D, medium | Rules code matches the reference on 14 of 14 checks; **the app crashes at start** (`ShowBase` has no `setTitle`), so not playable | wall cap (90 min), 166 calls |
| Rocket game, **Python/pygfx**, medium, OpenCode ([`pygfx-track/`](pygfx-track/README.md)) | Rules code matches the reference on 14 of 14 checks; **the app passes our probe 9 of 9** (the first Python app to do so); milestone 3 (integration checks) was not reached | wall cap (90 min), 135 calls |
| Rocket game, Python/Panda3D, medium, **OpenCode instead of Pi** | Rules code matches the reference on 14 of 14 checks; **the app fails at its first import** (`CDFNode`) and was never run by the agent; not playable | wall cap (90 min), 113 calls |

Details, per-round tables and our own mistakes: [`results.md`](results.md). Traps for anyone rerunning this: [`../../docs/lessons.md`](../../docs/lessons.md) items 21-30.

## Safety

Same warnings as the other evals: no sandbox here. Pi has no permission system, the shims block commands by name only, and the probes execute code the model wrote. Use a disposable environment. `server/` contains examples only; `bin/round.sh` does not change services. The rocket harness's `swap.sh` (not used for Inkling) does.
